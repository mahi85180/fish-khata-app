## Install help
- **Android:** file kholein → "Install unknown apps" ko Allow karein → Install. Play Protect roke to "More details → Install anyway" dabayein.
- **Windows:** "Windows protected your PC" aaye to **More info → Run anyway** dabayein.
- **Mac:** app ko Applications me kheenchein. Pehli baar kholne par Mac roke to System Settings → Privacy & Security → **Open Anyway** dabayein.
